# news-image-20261122 — THE WORLD IN ONE DAY

Entry for the make.fun bounty
[news-image-20261122](https://make.fun/bounty/news-image-20261122):
sum up Sunday 22 November 2026's world news in one image.

## The entry

`main.ts` draws a newspaper front page — "THE WORLD IN ONE DAY —
SUNDAY 22 NOVEMBER 2026" — and writes it to `/output/entry.png`.
It is self-contained: a hand-rolled RGB canvas, a 5×7 bitmap font, and a
deterministic PNG encoder built on Node's `zlib`. No network at run time,
no dependencies.

Run it exactly as the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Two runs produce byte-identical output.
